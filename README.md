# ARAM Picker

用于在《英雄联盟》大乱斗选人阶段自动快速选择替补席英雄。

## 功能

- 自动检测英雄联盟客户端和大乱斗选人阶段
- 显示当前英雄、替补席英雄和选人倒计时
- 点击替补席英雄即可交换；处于冷却时会等待后自动尝试
- 可选自动接受对局
- 进入选人阶段时窗口自动置顶，结束后恢复普通窗口

## 环境要求

- Windows 10 或 Windows 11
- Python 3.10 及以上版本
- 英雄联盟客户端

## 从源码运行

在 PowerShell 中进入项目目录，然后执行：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

程序可以先于英雄联盟客户端启动。连接成功后，顶部状态会变为“已连接客户端”。

## 使用方法

1. 启动程序和英雄联盟客户端。
2. 进入大乱斗选人阶段，工具窗口会自动置顶。
3. 在左侧列表点击想要的英雄；再次点击已登记的英雄可取消等待。
4. 如需自动接受匹配，打开顶部的“自动接受对局”开关。

## 常见问题

### 一直显示“客户端未连接”

确认英雄联盟客户端已经启动。如果客户端以管理员身份运行，工具也可能需要使用相同权限启动。

### 英雄名称显示为编号

工具会优先读取客户端内置的中文名称，其次读取本地缓存，最后尝试访问 Data Dragon。网络暂时不可用不会影响交换功能。

### 点击后没有立即交换

客户端对替补席交换有冷却限制。工具会显示剩余时间，并在冷却结束后尝试交换；目标被队友换走时会自动取消。

### 客户端更新后功能失效

LCU 是客户端本地接口，可能随客户端版本变化。请在 GitHub Issue 中附上工具日志和客户端版本，不要上传 lockfile 或认证令牌。
